# 제주 사토루 (Jeju Satoru): 제주 방언-표준어 변환 모델 개발 프로젝트

## 1. 프로젝트 소개
'제주 사토루' 프로젝트는 유네스코에서 '소멸 위기 언어'로 지정한 제주어의 보존과 활용을 목표로 개발된 AI 번역 모델입니다. 본 프로젝트는 3주간의 PoC(개념 증명) 기간 동안 제주어-표준어 양방향 번역 모델의 실현 가능성을 검증하고 핵심 기술을 확보하는 데 집중했습니다.

궁극적으로 '제주 사토루'는 단순히 언어적 소통의 불편함을 해소하는 것을 넘어, 제주어 화자의 디지털 소외 문제를 해결하고 제주어의 문화적 가치를 보존하는 중요한 첫걸음이 되고자 합니다.



## 2. 프로젝트 폴더 구조
프로젝트의 효율적인 협업과 체계적인 관리를 위해 다음과 같은 폴더 구조를 사용합니다.

* `data/`: 모델 학습에 사용되는 모든 데이터를 관리합니다.
* `models/`: 파인튜닝이 완료된 단일 모델 파일과 토크나이저를 저장합니다.
* `notebooks/`: 데이터 탐색 및 모델 실험을 위한 Jupyter Notebook 파일들을 보관합니다.
* `demo/`: 학습된 모델을 활용한 데모 구현 코드가 저장됩니다.
    * `web/`: 웹 페이지 코드가 저장됩니다.



## 3. 기술 스택
* **언어**: Python, JavaScript
* **프레임워크**: PyTorch, Flask, React
* **라이브러리**: Hugging Face `transformers`, `datasets`, `accelerate`, `evaluate`, `sacrebleu`, `bert-score`, `kiwipiepy`, `gevent`, `gevent-websocket`
* **모델 아키텍처**: Transformer (인코더-디코더 구조)
* **사전 학습 모델**: **KoBART (gogamza/kobart-base-v2)**



## 4. Git 워크플로우
본 프로젝트는 `git-flow`와 유사한 브랜칭 전략을 사용합니다.
* `main` 브랜치: 배포 가능한 안정적인 코드를 유지합니다.
* `develop` 브랜치: 개발의 중심이 되는 브랜치입니다. 모든 팀원은 이 브랜치를 기반으로 작업합니다.
* `feature/<task-name>` 브랜치: 개별 태스크를 위해 `develop`에서 분기하여 사용합니다.
* Pull Request (PR): `feature` 브랜치를 `develop` 브랜치로 병합할 때 코드 리뷰를 요청하는 데 사용합니다.



## 5. 핵심 폴더별 README 요약

### `./data/README.md`
이 문서는 모델 학습에 사용된 데이터셋의 상세 정보를 담고 있습니다. 데이터는 허깅페이스의 `Junhoee/Jeju-Standard-Translation` 데이터셋을 활용했으며, **자카드 계수 기반의 필터링**과 **Kiwi 라이브러리**를 사용한 텍스트 정제를 거쳤습니다. 양방향 번역 학습을 위해 태그를 추가하고 데이터를 통합한 과정을 상세히 설명합니다.

### `./models/README.md`
이 문서는 학습된 모델에 대한 기술적 정보를 제공합니다. 기반 모델인 `gogamza/kobart-base-v2`를 활용하여 **2단계 도메인 적응 기법**을 적용해 파인튜닝했습니다. 주요 하이퍼파라미터(Learning Rate, Epochs 등)와 모델 성능 지표(SacreBLEU, CHRF, BERTScore)를 명시하고, 모델의 허깅페이스 허브 링크를 제공하여 사용자가 쉽게 접근할 수 있도록 했습니다.

### `./demo/web/README.md`
이 문서는 웹 기반 번역 데모의 실행 방법을 안내합니다. **React**와 **Flask**를 사용하여 프론트엔드와 백엔드를 구축했으며, **웹소켓(SocketIO)** 통신을 통해 실시간으로 번역 결과를 제공하는 것이 특징입니다. 프론트엔드와 백엔드 서버를 각각 실행하는 방법을 단계별로 설명하여, 누구나 쉽게 데모를 구동할 수 있도록 했습니다.


## 6. 확장성 및 비전

본 프로젝트의 최종 목표는 양방향 텍스트 번역 모델을 넘어, 제주어 화자의 디지털 소외 문제를 실질적으로 해결하는 것입니다.

* **음성 기반 번역 시스템**: 텍스트 기반 모델을 성공적으로 구현한 후, AI Hub의 음성 데이터를 활용하여 제주 방언 음성 인식(ASR) 모델을 추가로 개발하는 로드맵을 수립할 수 있습니다. 이를 통해 음성 입력만으로 번역이 가능한 사용자 친화적 인터페이스를 구축하여 제주어 사용자들이 스마트폰이나 키오스크 같은 디지털 기기를 더 쉽게 활용할 수 있게 될 것입니다.
* **다단계 번역 시스템**: '제주 방언 → 표준어' 모델을 확장하여 '제주 방언 → 표준어 → 영어'와 같은 다단계 번역 시스템을 구축할 수 있습니다. 이 시스템은 제주어를 사용하는 사람들이 글로벌한 소통을 할 수 있도록 지원하며, 제주어를 세계에 알리는 교두보 역할을 할 것으로 기대합니다. 다만, 이 과정에서 발생하는 **오류 전파(Error Propagation)** 문제를 최소화하기 위한 구조적 보완이 필수적입니다.
