# 제주 사토루: 학습 데이터셋 가이드

본 문서는 '제주 사토루' 프로젝트의 핵심인 제주어-표준어 번역 모델 학습에 사용된 데이터셋에 대한 상세 정보를 제공합니다. 데이터셋은 모델의 성능에 직접적인 영향을 미치므로, 그 출처와 처리 과정을 투명하게 공개합니다.

## 1. 데이터 출처 및 구성

저희 프로젝트는 직접적인 데이터 수집보다는, 기존에 공개된 대규모 병렬 말뭉치를 활용하는 전략을 채택했습니다. 이는 짧은 프로젝트 기간 내에 양질의 데이터를 확보하기 위함이었습니다.

* **주요 출처**: Hugging Face에 공개된 `Junhoee/Jeju-Standard-Translation` 데이터셋을 활용했습니다. 이 데이터셋은 약 93만 개의 문장 쌍으로 이루어져 있습니다.
* **원본 소스**: `Junhoee/Jeju-Standard-Translation` 데이터셋은 주로 **카카오브레인 JIT (Jeju-Island-Translation)** 및 **AI Hub 제주어 발화 음성 데이터**의 전사 텍스트를 기반으로 구축되었습니다.

## 2. 데이터 전처리 및 필터링

모델 학습에 사용된 데이터는 모델의 안정적인 학습을 위해 다음과 같은 필터링 및 전처리 과정을 거쳤습니다.

### 2.1. 데이터 필터링

데이터의 품질을 높이기 위해 문장 유사도와 길이를 기준으로 데이터를 필터링했습니다.

* **문장 유사도 필터링**: **자카드 계수(Jaccard Similarity)**를 활용하여 표준어와 제주어 문장 간의 유사도를 측정했습니다. 자카드 계수 값이 0.1 이상 0.9 이하인 문장 쌍만을 선택하여, 너무 유사하거나 전혀 관련 없는 문장을 제외했습니다.
* **문장 길이 필터링**: 문장의 길이가 10자 이상, 40자 이하인 데이터만 추출하여 모델 학습에 적합한 데이터셋을 구축했습니다.

### 2.2. 텍스트 정제 (Text Cleaning)

모델이 텍스트를 정확하게 이해하도록 다음과 같은 텍스트 정제 작업을 수행했습니다.

* **띄어쓰기 교정**: Kiwi 라이브러리를 사용해 문장의 띄어쓰기를 교정하여 문법적 오류를 최소화했습니다.
* **불필요한 문자 제거**: 한글, 숫자, 공백을 제외한 모든 특수문자를 제거했습니다.
* **공백 정돈**: 여러 개의 공백을 하나의 공백으로 통일하고, 문장 앞뒤의 불필요한 공백을 제거했습니다.

## 3. 학습용 데이터셋 구축

전처리된 데이터를 기반으로 모델 학습을 위한 최종 데이터셋을 구축했습니다.

* **태그 추가**: 각 문장 앞에 언어를 식별할 수 있는 태그(`[제주]` 또는 `[표준]`)를 추가했습니다. 이는 모델이 번역의 방향을 명확하게 인지하는 데 필수적입니다.
* **양방향 데이터셋 결합**: '제주 방언 → 표준어' 데이터와 '표준어 → 제주 방언' 데이터를 각각 만든 후, 이 두 데이터프레임을 하나로 합쳐 양방향 번역 학습을 위한 데이터셋을 완성했습니다.
* **데이터 무작위 섞기**: 최종 데이터프레임을 무작위로 섞어 모델이 특정 데이터 순서에 편향되지 않도록 했습니다.
