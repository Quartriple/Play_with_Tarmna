# 제주 사토루: 웹 데모 가이드

이 폴더는 '제주 사토루'의 웹 기반 번역 데모를 실행하기 위한 파일들을 포함하고 있습니다. 이 데모는 사용자가 직접 텍스트를 입력하여 제주어와 표준어 간의 양방향 번역 기능을 체험해볼 수 있도록 구현되었습니다.

## 1. 기술 스택

웹 데모는 다음과 같은 기술 스택을 사용하여 구축되었습니다.

* **프론트엔드**: React
* **백엔드**: Python (Flask/FastAPI) 및 SocketIO
* **번역 모델**: Hugging Face `transformers` 라이브러리를 활용하여 학습된 모델을 사용합니다.

## 2. 웹 데모 실행 방법

웹 데모는 프론트엔드와 백엔드 서버를 각각 실행해야 합니다.

### 2.1. 백엔드 서버 실행

백엔드 서버는 Python 기반으로, 번역 모델의 추론을 담당합니다.

1.  **필수 라이브러리 설치**: `app.py`에 필요한 파이썬 라이브러리들을 설치합니다.
    ```bash
    pip install Flask Flask-Cors Flask-SocketIO transformers gevent gevent-websocket
    ```
2.  **모델 파일 준비**: 학습된 모델 파일들을 백엔드 서버가 접근할 수 있는 경로에 위치시켜야 합니다. `app.py` 파일의 `model_path` 변수(`../../../models/jeju_satoru`)를 모델이 저장된 실제 경로로 수정하거나, 해당 경로에 모델 파일들을 복사합니다.
3.  **서버 실행**: `app.py` 파일을 실행합니다.
    ```bash
    python app.py
    ```

### 2.2. 프론트엔드 실행

프론트엔드는 React 기반이며, 사용자의 입력을 받아 백엔드에 전달하고 번역 결과를 화면에 표시합니다.

1.  **종속성 설치**: `package.json` 파일에 정의된 노드 종속성들을 설치합니다.
    ```bash
    npm install
    ```
2.  **프론트엔드 서버 실행**: 서버를 시작합니다.
    ```bash
    npm start
    ```
    브라우저에서 `http://localhost:3000`으로 접속하여 데모를 확인할 수 있습니다.

## 3. 웹 데모 주요 기능

* **양방향 번역**: '제주어 → 표준어' 및 '표준어 → 제주어' 번역을 토글 버튼으로 전환할 수 있습니다.
* **실시간 번역**: 웹소켓(SocketIO) 통신을 활용하여 번역 결과를 단어 단위로 실시간 스트리밍합니다. 이 방식은 긴 문장의 번역 과정에서 사용자 경험을 향상시킵니다.
